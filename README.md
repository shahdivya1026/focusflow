# 🌸 FocusMate – Your Productivity Space

FocusMate is a student productivity web application designed to help you stay organized, manage tasks, plan your schedule, and improve focus — all in one place. ✨

### 🚀 Features
- ✅ Task Management with Search & Filters
- 📅 Interactive Calendar with Events, Notes & Reminders
- ⏱️ Focus Timer & Pomodoro Sessions
- 📊 Focus History and Productivity Tracking
- 👤 User Authentication & Profile Management
- 🎨 Clean, Modern & Soft Pink UI

### 🛠️ Tech Stack
- **Frontend:** Next.js, React, JavaScript, CSS
- **Backend:** Next.js API Routes
- **Database:** MariaDB
- **ORM:** Prisma
